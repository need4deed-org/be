# plzs-all-de.json

Every German postal code (PLZ) with a centroid, from the [GeoNames](https://www.geonames.org/)
postal code export `DE.zip` (https://download.geonames.org/export/zip/), licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Includes PO-box and large-recipient PLZs. GeoNames lists one row per place a PLZ covers;
`latitude`/`longitude` are the mean of those rows, rounded to 6 decimals.
