# plzs-all-de.json

German postal codes (one row per PLZ, coordinates averaged over its places) from the
[GeoNames](https://www.geonames.org/) postal code export `DE.zip`
(https://download.geonames.org/export/zip/), licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Includes PO-box and large-recipient PLZs.
